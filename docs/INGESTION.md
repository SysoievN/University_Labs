# Передача Teams → GitHub → Codex

1. Агент Teams читає свіжі завдання й отримує файли без зміни університетських даних.
2. Перевіряє студентські персональні дані й секрети, включно з метаданими. Неперевірені файли не комітить.
3. Для безпечних оригіналів записує контрольну суму й маніфест. Для очищених копій чесно вказує redacted. Проблеми завантаження залишає блокерами.
4. Оновлює TASK.md, вимоги й каталог. Невідомий варіант/часовий пояс/дедлайн не вгадує.
5. Перевіряє PRIVATE та комітить. Локальний Codex виконує pull, читає правила й отримує всі відстежувані файли без ручного копіювання.
6. Codex зберігає прогрес у progress/, код у work/, персоналізовані звіти поза Git у private-local/. Перед здачею потрібен окремий дозвіл користувача.
