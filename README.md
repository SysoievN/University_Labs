# University_Labs

Приватне спільне сховище актуальних університетських завдань. Поточний каталог: 8 дисциплін, 20 опублікованих робіт і 4 методички АВД без строків. Фізкультуру та роботи з простроченням 4+ місяці виключено.

## Структура

- AGENTS.md — правила для агентів і приватності.
- TASKS.md — список робіт і первинні статуси.
- catalog/tasks.json — машинний каталог зі стабільними ID, строками та блокерами.
- `courses/<discipline>/lab-NN/TASK.md` — окрема постановка кожної роботи.
- `courses/<discipline>/REQUIREMENTS.md` — прочитані вимоги до виконання/звіту.
- `courses/<discipline>/sources/MANIFEST.json` — стан отримання файлів; originals/ і redacted/ з'являються тільки після перевірки.
- progress/ — актуальні статуси локального Codex.
- `work/<task-id>/` — код, тести та знеособлені звіти.
- docs/ — аудит і правила передачі.
- scripts/Sync-Tasks.ps1 — отримання оновлень у чистий checkout без ручного копіювання файлів.

## Початкове підключення Windows

Один раз клонуй приватний репозиторій під своїм GitHub-акаунтом через VS Code Git: Clone або Git Credential Manager, відкрий папку у VS Code та Codex. Токени не записувати у URL або файли.

```powershell
git clone https://github.com/SysoievN/University_Labs.git
cd University_Labs
code .
```

Перед новим дорученням Codex виконує `git pull --ff-only` або `powershell -File scripts/Sync-Tasks.ps1`. Після commit агента Teams файли отримуються цією командою; повторно копіювати вкладення вручну не потрібно. Це синхронізація на запит, не фоновий моніторинг Teams.

Стартове доручення Codex: «Прочитай AGENTS.md і TASKS.md, синхронізуй чистий checkout, покажи найближчі ready-завдання та блокери. Потім працюй над лабораторною, яку я оберу».
