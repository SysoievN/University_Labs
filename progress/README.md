# Прогрес локального Codex

Один JSON на task-id. Статуси: not_started, in_progress, blocked, ready_for_review, completed_local. Поля: task_id, status, updated_at, outputs, validation, blockers. До створення запису початковий стан — not_started. Жодних персональних даних і секретів. Агент Teams не перезаписує ці файли.
