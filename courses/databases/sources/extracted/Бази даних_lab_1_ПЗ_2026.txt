Тема: "Розробка бази даних в СУБД MS SQL Server з графічним багатовіконним користувацьким інтерфейсом "

Постановка завдання
Розробити застосунок у середовищі Visual Studio для роботи з базою даних засобами СУБД MS SQL Server, що забезпечує   введення, перегляд,   редагування  даних й виконання запитів користувача для декількох зв'язаних таблиць.

Загальні вимоги
1. Предметна область – з окремого файлу за номером студента у списку групи.
2. СУБД - MS SQL Server з ОБОВ'ЯЗКОВОЮ установкою MS SQL Management Studio.
3. Середовище розроблення проєкту Visual Studio. Мова програмування C#.
