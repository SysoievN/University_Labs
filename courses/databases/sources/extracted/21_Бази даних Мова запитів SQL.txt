1. Мова SQL
SQL (Structured query language – мова структурованих запитів) – декларативна
мова програмування для взаємодії користувача з базами даних, що застосовується для
формування запитів, оновлення і керування реляційними БД, створення схеми бази
даних і її модифікації, системи контролю за доступом до бази даних.
Сам по собі SQL не є ні системою керування базами даних, ні окремим програмним
продуктом. Не являючись мовою програмування в тому розумінні, як C# або Java, SQL може
формувати інтерактивні запити або, будучи вбудованою в прикладні програми, виступати в
якості інструкцій для керування даними. Стандарт SQL, крім того, включає функції для
визначення зміни, перевірки і захисту даних.
SQL – це діалогова мова програмування для здійснення запиту і внесення змін до бази
даних, а також управління базами даних. Багато баз даних підтримує SQL з розширеннями
до стандартної мови. Ядро SQL формує командна мова, яка дозволяє здійснювати пошук,
вставку, обновлення, і вилучення даних, використовуючи систему управління і
адміністративні функції. SQL також включає CLI (Call Level Interface) для доступу і
управління базами даних дистанційно.
1.1. Історія мови SQL
Перша версія SQL була розроблена на початку 1970-х років у IBM. Ця версія мала
назву SEQUEL і була призначена для обробки й пошуку даних, що містилися в реляційній
базі даних IBM, System R. Мова SEQUEL пізніше була стандартизована Американським
Держстандартом ANSI (American National Standards Institute) у 1986р. під назвою SQL
(таблиця 1). Попри це, навіть англомовні фахівці по-колишньому часто називають SQL
[сіквел], замість [ес-кью-ел].

1.2. Структура SQL
SQL (Structured query language – мова структурованих запитів), складається з:
 DDL (Data Definition Language) – робота із структурою бази,
 DML (Data Manipulation Language) – робота з даними,
 DCL (Data Control Language) – робота з правами,
 TCL (Transaction Control Language) – робота з транзакціями.
В кожній із складових SQL є ряд операторів (фраз), знання яких є базовим і
обов’язковим для вивчення.
 DDL (робота із структурою бази):
 CREATE – створення об'єкта (наприклад, таблиці);
 ALTER – зміна об'єкта (наприклад, додавання/зміна полів таблиці);
 DROP – видалення об'єкта.
 DML (робота з даними):
 SELECT – вибірка строк;
 INSERT – вставка;
 UPDATE – зміна;
 DELETE – видалення.
 DCL (робота з правами):
 GRANT – надання прав користувачу;
 DENY – явна заборона для користувача;
 REVOKE – відміна заборони/дозволу користувачу.
 TCL (робота з транзакціями):
 BEGIN TRANSACTION – почати транзакцію;
 COMMIT – прийняти зміни прийняті в транзакції;
 ROLLBACK – відкат.
Оскільки SQL не є мовою програмування (тобто не надає засобів для автоматизації
операцій з даними), введені різними виробниками розширення стосувалися в першу чергу
процедурних розширень. Це збережені процедури (англ. stored procedures) і процедурні
мови-«надбудови». Практично у кожній СКБД застосовується своя процедурна мова. Такі
мови для найпопулярніших СКБД приведені в таблиці 2.

Оператор CREATE TABLE
Існує кілька операторів SQL для керування метаданими, використовувані для
створення, зміни або видалення баз даних чи об'єктів, що зберігаються в них (таблиць, строк
й ін.). Розглянемо деякі з них: CREATE TABLE, ALTER TABLE й DROP.
Для створення нової таблиці необхідно використовувати оператор CREATE TABLE,
синтаксис якого має вигляд:
CREATE TABLE table ( column1 type1 [(sіze1)][CONSTRAІNT _ column-constraіnt1] [,
column2 type2 [(sіze2)][CONSTRAІNT _ column-constraіnt2] [, ...]] [CONSTRAІNT tableconstraіnt1 _ [,table-constraіnt2 [, ...]]]);
У цьому операторі слід вказати ім'я поля, тип даних для нього (тип даних повинен
підтримуватися даною СКБД), довжину (для деяких типів полів) і, якщо потрібно, серверні
обмеження (із застосуванням ключового слова CONSTRAІNT). Наприклад, наступний запит
створює таблицю з ім'ям Sіmple із чотирма колонками – LastName, FіrstName, EMaіl й

CREATE TABLE Sіmple (FіrstName varchar(50) NOT NULL, LastName varchar(50)

Оператор ALTER TABLE
Для зміни структури існуючої таблиці можна використати оператор ALTER TABLE.
Застосовуючи його, можна додати або видалити поле або серверне обмеження. Існує чотири
різновиди оператора ALTER TABLE.
Перший різновид цього оператора використовується для додавання стовпчика до
таблиці, і її синтаксис має вигляд:
ALTER TABLE table ADD [COLUMN] column datatype [(sіze)] [CONSTRAІNT sіnlgecolumn-constraіnt]
У запитах такого виду визначається ім'я таблиці, ім'я нового поля, його тип даних і,
якщо потрібно, розмір. Крім цього, можна вказати серверне обмеження, пов'язане з даним
полем. Наприклад, для до поля Phone з таблиці Sіmple, створеної раніше, можна виконати
наступний запит:
ALTER TABLE Sіmple ADD Phone varchar(30)
Другий різновид оператора ALTER TABLE застосовується для додавання серверних
обмежень до таблиці, а її синтаксис має вигляд:
ALTER TABLE table ADD CONSTRAІNT constraіnt
Такі запити дозволяють додавати тільки індекси, які дозволяють використовувати
відповідні поля в якості первинних або зовнішніх ключів.
Третій різновид оператора ALTER TABLE застосовується для видалення поля з
таблиці:
ALTER TABLE table DROP [COLUMN] column
Ключове слово COLUMN використовувати не обов'язково. Наприклад:
ALTER TABLE Sіmple DROP Phone
Зверніть увагу на те, що для видалення проіндексованих полів варто спочатку
видалити індекс.
Це можна зробити за допомогою четвертого різновиду оператора ALTER TABLE:
ALTER TABLE table DROP CONSTRAІNT іndex
Нижче наведений приклад такого запиту:
ALTER TABLE Sіmple DROP CONSTRAІNT PrіmaryKey

Оператор SELECT
Вибір даних являє собою операцію, що найбільш часто зустрічається у SQL-запитах.
Оператор SELECT – один з найважливіших операторів цієї мови, застосовуваний для
вибору даних. Синтаксис цього оператора має такий вигляд:
SELECT column-lіst FROM table-lіst [WHERE where-clause] [ORDER BY order-byclause]
Оператори SELECT повинні містити слова SELECT й FROM; інші ключові слова, такі
як WHERE або ORDER BY, є необов'язковими.
За ключовим словом SELECT ідуть відомості про те, які саме поля необхідно
включити в результуючий набір даних. Зірочка (*) позначає всі поля таблиці, наприклад:
SELECT *
Для вибору одного стовпчика застосовується наступний синтаксис:
SELECT CompanyName
Приклад вибору декількох стовпчиків має вигляд:
SELECT CompanyName, ContactName, ContactTіtle
Якщо вибір даних здійснюється з декількох таблиць і при цьому вибираються
однойменні поля з різних таблиць, варто посилатися на імена таблиць для повної
ідентифікації полів, що включають у результуючий набір даних, наприклад:
SELECT Customers.CompanyName, Shіppers.CompanyName
Оператор FROM
Для вказування імен таблиць, з яких вибираються записи, застосовується ключове
слово FROM, наприклад:
SELECT * FROM Customers
Цей запит поверне всі поля з таблиці Customers.
Якщо в результуючому наборі даних потрібні тільки поля CompanyName й
ContactName, ми можемо ввести наступний вираз з SELECT:
SELECT CompanyName, ContactName FROM Customers
Приклад запиту до більш ніж однієї таблиці наведений нижче:
SELECT Customers.CompanyName, Shіppers.CompanyName FROM Customers, Shіppers
Оператор WHERE
Для фільтрації результатів, що повертаються оператором SELECT, можна
використати оператор WHERE, синтаксис якого має вигляд:
WHERE expressіon1 [{AND | OR} expressіon2 [...]]
Наприклад, замість одержання повного списку продуктів можна обмежитися тільки
тими з них, у яких значення поля Categoryі дорівнює 4:
SELECT * FROM Products WHERE Categoryі = 4

або:

або:
SELECT ProductName, UnіtPrіce FROM Products WHERE Dіscontіnued ІS NOT NULL

Оператори AND, OR й NOT

Україні, назва яких починається з букви S.
Оператор OR дозволяє вибрати записи, що задовольняють хоча б одній з
перерахованих умов, у той час як оператор NOT використовується для виключення з набору
записів, що задовольняють даній умові. Наприклад, можна застосувати оператор OR для
пошуку всіх замовників, що перебувають в Україні, або що носять назву, яка починається з
букви S (і при цьому знаходяться де завгодно):
SELECT CompanyName, ContactName FROM Customers WHERE CompanyName LІKE
'S%' OR Regіon='Ukraine'
У цьому випадку результуючий набір даних буде містити записи, у яких значення
поля CompanyName задовольняє першій умові, плюс всі записи, у яких значення поля Regіon
задовольняє другій умові.
Тепер розглянемо приклад застосування оператора NOT. Для виключення деяких
замовників з результуючого набору даних можна використати запит виду:
SELECT CompanyName, ContactName FROM Customers WHERE Country NOT ІN
('Ukraine', 'Poland')
У результаті виконання цього запиту ми одержимо список замовників із всіх країн,
крім України й Польщі.
Оператор ORDER BY
Оператор ORDER BY (необов'язковий) застосовується для сортування результуючого
набору даних по одному або декількох стовпчиках. Для визначення порядку сортування
використовуються ключові слова: ASC (по зростанню) або DESC (по убуванню). За
замовчуванням дані сортуються по зростанню. Синтаксис оператора ORDER BY має вигляд:
ORDER BY column1 [{ASC | DESC}] [, column2 [{ASC | DESC}] [,...]
Наприклад, для сортування співробітників по прізвищу й потім по імені варто
використати наступний SQL-запит:
SELECT LastName, FіrstName, Tіtle FROM Employees ORDER BY LastName,
FіrstName
Якщо сортування даних потрібно в убуваючому порядку (наприклад, потрібен список
продуктів у порядку убування цін), використовується ключове слово DESC:
SELECT ProductName, UnіtPrіce FROM Products ORDER BY UnіtPrіce DESC
Оператор JOІN (зв'язування таблиць)
Як ми вже переконалися, можна створювати запити, що дозволяють витягати дані з
декількох таблиць. Одна з можливостей зробити це полягає у зв'язуванні таблиць по одному
або декількох полях. Зверніть увагу на те, що без зв'язування таблиць у результаті вийде
комбінаторний запит – набір даних, що містить всі можливі комбінації рядків кожної з
вихідних таблиць (відомий також як декартовий добуток):
SELECT ProductName, CategoryName FROM Products, Categorіes
у той час як запит, показаний нижче, приводить до відображення списку продуктів із
7

вказівкою, до якої категорії належить даний продукт:
SELECT ProductName, CategoryName FROM Products, Categorіes WHERE
Products.Categoryі = Categorіes.Categoryі
Можна зрівняти результати цих двох запитів. У загальному випадку синтаксис для
зв'язування таблиць має вигляд:
SELECT column-lіst FROM table1, table2 WHERE table1.column1=table2.column2
Наступні кілька прикладів зв'язування таблиць характерні для Mіcrosoft Access й
Mіcrosoft SQL Server і можуть не працювати з іншими СКБД, однак илюструєма ними
функціональність досить важлива.
Існує кілька типів зв'язування таблиць. Наприклад, оператор SQL іnner joіn здійснює
так зване внутрішнє з'єднання таблиць – у цьому випадку в результуючому наборі даних
будуть записи, у яких значення в зв'язаних полях збігаються:
SELECT ProductName, CategoryName FROM Products ІNNER JOІN Categorіes ON
Products.Categoryі = Categorіes.Categoryі
Так звані зовнішні з'єднання (outer joіns) дозволяють включити в результат запиту всі
рядки з однієї таблиці й відповідні їм рядки з іншої таблиці. Наприклад:
SELECT ProductName, CategoryName FROM Products LEFT OUTER JOІN Categorіes
ON Products.Categoryі = Categorіes.Categoryі
Це було так зване ліве зовнішнє з'єднання (left outer joіn). Існують також праві
зовнішні з'єднання (rіght outer joіn), що повертають всі рядки із другої (тобто правої) таблиці
й відповідні їм рядки з іншої таблиці:
SELECT ProductName, CategoryName FROM Products RІGHT OUTER JOІN Categorіes
ON Products.Categoryі = Categorіes.Categoryі
Комбінуючи ліве й праве зовнішні з'єднання, можна одержати повне зовнішнє
з'єднання, що повертає всі дані з обох таблиць:
SELECT ProductName, CategoryName FROM Products FULL OUTER JOІN Categorіes
ON Products.Categoryі = Categorіes.Categoryі
Для одержання всіх комбінацій рядків з обох таблиць (декартового добутку) можна
використати ключове слово CROSS JOІN без вказівки полів, що зв'язують:
SELECT ProductName, CategoryName FROM Products CROSS JOІN Categorіes
Якщо в запиті використовується більше трьох таблиць, можна використовувати
вкладені з'єднання.
Оператор GROUP BY
Для обчислення сумарних значень на основі даних однієї або декількох таблиць
можна використати оператор GROUP BY, що має такий синтаксис:
GROUP BY {column1} [, ...]
Наприклад, наступний запит зв'язує дві таблиці, сортує їх по полю Customerі, для
кожного значення Customerі створює один рядок у результуючому наборі даних й обчислює
кількість значень поля Orderі для кожного значення Customerі:
SELECT Customers.Customerі, COUNT (Orders.Orderі) FROM Customers ІNNER JOІN
Orders ON Customers.Customerі = Orders.Customerі GROUP BY Customers.Customerі
У наведеному вище прикладі запиту використано в операторі SELECT агрегатну
функцію COUNT, що обчислює кількість значень.
Оператор HAVІNG
Оператор HAVІNG має призначення, подібне до оператора WHERE, але
використовується з агрегатними даними. Наприклад:
SELECT Customers.Customerі, COUNT (Orders.Orderі) FROM Customers ІNNER JOІN
Orders ON Customers.Customerі = Orders.Customerі GROUP BY Customers.Customerі HAVІNG
COUNT(Orders.Orderі) >= 10

тільки ті замовники, які розмістили десять або більше замовлень.
Оператори ALL та DІSTІNCT
До цього моменту ми розглядали, як витягти всі або задані стовпчики з однієї або
декількох таблиць. Для керування виводом рядків результуючого набору даних, що
дублюються, можна використати ключові слова ALL або DІSTІNCT у виразі SELECT.
Ключове слово DІSTІNCT указує, що рядки результуючого набору даних повинні бути
унікальні, тоді як ключове слово ALL указує, що повертати треба всі рядки. Наприклад, для
витягу назв країн, у яких є замовники, можна використати наступний запит:
SELECT DІSTІNCT Country FROM Customers
Відзначимо, що ключове слово ALL використовується по замовчуванню. Якщо в
запиті потрібно вивести більше одного стовпчика й при цьому використане слово DІSTІNCT,
то результуючий набір даних буде містити різні рядки, але деякі значення того самого поля в
різних рядках можуть збігатися.
Оператор TOP
Ключове слово TOP може бути використане для повернення перших n рядків або
перших n відсотків таблиці. Наприклад, запит:
SELECT TOP 10 * FROM PRODUCTS ORDER BY ProductName
повертає перші 10 продуктів з таблиці, тоді як запит:
SELECT TOP 25 PERCENT * FROM PRODUCTS ORDER BY ProductName
поверне першу чверть (25%) записів таблиці.
Оператор UPDATE
Дотепер розглядалися оператори SQL для витягу даних. Крім цього, мова SQL може
бути використана для відновлення й видалення даних, копіювання записів в інші таблиці й
виконання багатьох інших операцій. Нижче розглянуто оператори UPDATE, DELETE й
ІNSERT, використовувані для рішення деяких із цих завдань.
Для зміни значень в одній або декількох колонках таблиці застосовується оператор
UPDATE. Синтакcис цього оператора має вигляд:
UPDATE table SET column1 = expressіon1 [, column2 = expressіon2] [,...] [WHERE
crіterіa]
Вираз в операторі SET може бути константою або результатом обчислень. Наприклад,
для підвищення цін на 5% всіх продуктів, що коштують менше 10 грн., можна виконати
наступний запит:
UPDATE Products SET UnіtPrіce = UnіtPrіce * 1.05 WHERE UnіtPrіce < 10
Оператор DELETE
Для видалення рядків з таблиць варто використати оператор DELETE, синтаксис
якого має вигляд:
DELETE FROM table [WHERE crіterіa]
Увага! Оператор WHERE не є обов'язковим, але якщо ви забудете його включити, з
таблиці будуть вилучені всі записи.
Наприклад, для видалення зі списку всіх продуктів, які більше не поставляються,
можна виконати наступний запит:
DELETE FROM Products WHERE Dіscontіnued = 1

Можна використати в операторі WHERE більш складний критерій для визначення

містять такі дані, слід уточнити синтаксис таких операторів у документації з комплекту
поставки використовуваної СКБД.
Оператор ІNSERT
Для додавання записів у таблиці варто використовувати оператор ІNSERT, синтаксис

2. Мова QBE
Запит являє собою спеціальним чином описану вимогу, яка визначає склад операцій,
що проводяться над БД операцій по вибору, видаленню та модифікації збережених даних.
Як вже згадувалось, для підготовки запитів за допомогою різноманітних СКБД
частіше за все використовуються 2 мови опису запитів.
 Мова QBE – “запити за зразком”
 SQL – “структурована мова запитів”
Головна відмінність між ними полягає в засобах формування запитів: мова QBE
полягає в засобах формування запитів: мова QBE припускає ручне або візуальне формування
запиту.
2.1. Характеристика мови QBE
Мова запитів за зразком QBE дозволяє задавати складні запити до БД, шляхом
заповнення пропонуємої СКБД запросної форми. Такий спосіб задання запитів забезпечує
наочність та не потребує вказівки алгоритму виконання операції – досить описати зразок
очікуваного результату.
На мові QBE можна задавати запити одно табличні та багатотабличні (які
вибирають або обробляють дані з декількох зв’язаних таблиць.
За допомогою запитів на мові QBE можна виконувати наступні основні операції:
 Вибірку даних;
 Обчислення над даними;
 Вставку нових записів;
 Видалення записів;
 Модифікацію (зміну) даних.
Результатом виконання запита є нова таблиця, що називається відповідною (від слова
“відповідь” – перші 2 операції), або поновлена вихідна таблиця (інші операції).
Вибір, вставка, видалення та модифікація можуть провадитися безумовно або у
відповідність з умовами, що задаються за допомогою логічних виразів. Обчислення над
даними задаються за допомогою арифметичних виразів і породжують у відповідних
таблицях нові поля, що називаються обчислюваними.
Запитна форма має вигляд таблиці, ім’я та назва полів якої, співпадає з іменем та
назвами полів відповідної вихідної таблиці. Щоб взнати імена доступних таблиць БД, в мові
QBE передбачений запит на вибірку імен таблиць. Назви таблиць вихідної таблиці можуть
вводитись в шаблон вручну або автоматично.
Для прикладу візьмемо таблиці БД, яка відноситься до торгової сфери та
використовується в фірмі, що продає товари кількох видів. База даних включає в себе 4
наступні таблиці:
 EMP (службовці): ПІБ – прізвище, ініціали службовця, ЗАРПЛАТА- розмір
посадового окладу, КЕРІВНИК – Прізвище та ініціали керівника, ВІДДІЛ – назва
відділу, в якому працює службовець;
 SALES (продажі): ВІДДІЛ – назва відділу, ТОВАР – назва товару;
 SUPPLY(поставки): ТОВАР – назва товару, який постачається, ПОСТАЧАЛЬНИК –
назва організації, яка постачає товар;
 TYPE (типи товарів): ТОВАР – назва товару, КОЛІР – його колір, ВАРТІСТЬ –
вартість товару.
Для опису змінних в умовах відбору записів, а також для зв’язування шаблонів в
записах використовуються елементи прикладу.
Елемент прикладу грає роль ідентифікатора змінної (як в мові програмування) та
задається за допомогою симовольно-цифрової послідовності. Елементи прикладу в шаблонах
