Лабораторна робота № 3 з курсу «Якість програмного забезпечення та тестування»
Тема: «Тестування продуктивності за допомогою JMeter»

Постановка задачі
Запишіть простий сценарій навантажувального тестування (2-3 кроки)  для сайту, назва якого розпочинається з першої літери вашого прізвища, додайте “Results Tree” та “Graph results” до Thread Group. Запустіть сценарій з 5, 10 та 20 користувачами зі значенням “Ramp-up Period”, що дорівнює 10. Зробіть скріншот “Graph results”, проаналізуйте його у звіті.


1 варіант
Реалізувати сценарії тестування продуктивності для реєстрації, авторизації користувача, додавання обраної тварини до кошика, видалення з кошика та вихід з акаунту користувача на https://petstore.octoperf.com/. Для заповнення полів під час реєстрації користувача використайте декілька функцій Jmeter (наприклад, для генерації випадкового рядка, дати, числа, тощо). Зробіть перевірку того, що кожен тест виконано успішно.

2 варіант
Реалізувати сценарії тестування продуктивності для авторизації, реєстрації, видалення пацієнта  на https://openmrs.org/demo/. Для заповнення полів під час реєстрації пацієнта використайте декілька функцій Jmeter (наприклад, для генерації випадкового рядка, дати, числа, тощо). Зробіть перевірку того, що кожен тест виконано успішно.

3 варіант
Реалізувати сценарії тестування продуктивності для додавання, редагування, видалення комп’ютера  на http://computer-database.gatling.io/. Для заповнення полів під час додавання нового комп’ютера використайте декілька функцій Jmeter (наприклад, для генерації випадкового рядка, дати, числа, тощо). Зробіть перевірку того, що кожен тест виконано успішно.

За результатами виконання лабораторної роботи оформіть звіт. Вимоги до звіту: титульна сторінка, постановка задачі, опис розв’язку, тестування, висновки.
