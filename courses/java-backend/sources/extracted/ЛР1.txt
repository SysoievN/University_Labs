                                Лабораторні роботи


1. Інструмент автоматизації збирання проєктів Apache Maven.
Завдання:
Створити Java застосунок який реалізує наступний функціонал:
1. Проєкт збирається за допомогою maven без використання IDE
2.Застосунок повинен бути jar файлом, що запускається
3. Написати програму калькулятор, яка виконує чотири арифметичні
операції, а також обчислює завдання за вашим варіантом.

При запуску програми через комендний рядок будуть передаватися такі
аргументи:
number1 number2 operator

Приклади операндів:
100 -100+

В якості operator для завдання за варіантом можна використати знак
тильда: ~

Програма повинна вивести в консоль наступне повідомлення та
завершитись:
number1=100 number2=-100 operator=+ result=0

public interface Calc {
double addition(double a, double b);

double subtraction(double a, double b);

double multiplication(double a, double b);

double division(double a, double b);

String task( String[] args );
}

Після перевірки працездатності додатка необхідно створити файл
readme.md у каталозі calculator у якому коротко описати проект і його
компіляцію та запуск, приблизно так, наприклад:
# maven-multimodule-example

## This is application: charcounter
## charcounter takes parameters from command line and print count of
parameters ## characters to command line

* To build project execute in cmd:
> mvn clean package

* To run application execute in cmd:

// success scenario
> java -jar ./charcounter-main/target/charcounter-jar-with-
dependencies.jar Hello, application!

// fail scenario
> java -jar ./charcounter-main/target/charcounter-jar-with-
dependencies.jar
