# Технології Java Backend: перевірені вимоги

Збірка лише Apache Maven + текстовий редактор; використання IDE знижує оцінку на 2 бали. Прикріпити звіт та архів проєкту, захистити на лабораторному. Варіант — у «Список_варіантів.xlsx», персональний рядок ще не перевірено. Шаблон звіту: титульна сторінка з дисципліною, групою, ПІБ та навчальним роком; 1) постановка задачі; 2) розв’язання; 3) основні коментовані частини коду; 4) інтерфейс/інструкція користувача; 5) тестові приклади; 6) висновки. Числові розміри шрифту й полів у прочитаному шаблоні не визначено.

Джерело: вебперегляд Teams, 2026-10-09. Ці вимоги стосуються лише прямо зазначених номерів робіт. Не переносити їх автоматично на інші лабораторні.
