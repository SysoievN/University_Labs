## Методичка №1 і підтверджений варіант

Варіант **21** за прямою вказівкою користувача. CLI: рядок лише з 0/1 — двійкове число без знака; інші рядки — текст. Числа доповнити зліва нулями до довжини, кратної 4, й перетворити кожну четвірку на hex-цифру. Вивести загальну кількість параметрів, кількість чисел та їх шістнадцяткові значення. Перетворення реалізувати окремим методом. У таблиці курсу раніше знайдено **18**: це розбіжність із джерелом; робочий номер **21** встановлений користувачем, не підтверджений таблицею.

Maven multimodule: calc-api (Calc interface), calc-core (CalcImpl), calc-main (App). Чотири арифметичні операції плюс task(String[] args) за варіантом. CLI: два числа та оператор для арифметики; для ~ уточнити узгодження довільного String[] зі схемою number1 number2 operator; відображення аргументів/результату. Запуск JAR без IDE. README зі збіркою mvn clean package, запуском, успішними й помилковими прикладами. IDE знижує оцінку на 2 бали. РСО: лабораторні №1 Maven, №2 TDD/JUnit/Hamcrest/Mockito, №3 Spring/Hibernate/JPA/Spring Boot/REST по 25 балів; тест 25. Орієнтири РСО: тижні 5/8/16, тест тиждень 16. №2/3 поки не знайдено як опубліковані картки з повними методичками; дати не вигадувати.

Джерело уточнень: отримані повні файли, 2026-10-09; див. MANIFEST.json.
