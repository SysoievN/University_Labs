# Професійна робота у Microsoft 365: перевірені вимоги

№1 — OneDrive. Захист університетського акаунта, хмарна синхронізація й спільний документ у реальному часі. Звіт зі скриншотами виконання. Потрібен захист, без нього можливе зниження балів. Деталі посилання у Reference materials ще не прочитані. №2 — Word. Документ 8–10 сторінок на тему спеціальності або власну; сучасна тематична обкладинка з центральною ілюстрацією/великим заголовком. Вирівнювання по ширині; поля: ліве 2,5 см, верх/низ 2 см, праве 1,5 см; перший рядок 1,25 см; без інтервалів між абзацами. Шрифт, колір, розмір та інтервали мають відповідати доступності, конкретного універсального шрифту не задано. Стилі заголовків 1–3 та автоматичний зміст із налаштуваннями. Щонайменше 3 рисунки з автоматичними підписами знизу, 2 таблиці (одна з розрахунками й об’єктом формули в комірці) з підписами зверху; підписи по центру без крапки. Альтернативний текст рисункам і таблицям. Щонайменше 3 Equation-формули по центру з номерами праворуч у дужках. Перехресні посилання до рисунків/таблиць із оновленням. Не менше 5 джерел, посилання [n], керована бібліографія у стилі завдання. Перевірка доступності й її скриншот. Здати файл Word; окремий звіт не потрібен; захистити. №3 — Excel. На вибір два варіанти: (1) дашборд ОТГ, 5 аркушів — головний/населення/звернення/транспорт/бюджет, місячні дані, KPI, автоматизовані зведені таблиці, щонайменше 4 графіки; (2) магазин — кілька аркушів товарних груп, ціни/податок 22%/прибуток, запаси/терміни/продавці, підсумки, умовне форматування, діаграми продажів/попиту, зведені таблиці прибутку, прогноз поповнення, налаштування друку, захист аркушів і Flash Fill. Прикріпити файл Excel. Докладні числа й вихідні дані слід брати безпосередньо з методички при виборі варіанта.

Джерело: вебперегляд Teams, 2026-10-09. Ці вимоги стосуються лише прямо зазначених номерів робіт. Не переносити їх автоматично на інші лабораторні.
