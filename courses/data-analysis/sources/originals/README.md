# Перевірені оригінали АВД

Джерело: Teams поточного курсу → General → Навчальні матеріали → Лабораторні роботи → SharePoint. Отримано 2026-10-09.

Файли збережені без змін. SHA-256 і стан перевірки — у ../MANIFEST.json. Перевірено текст PDF, XML/метадані DOCX та вміст архівів. Даних студентських списків, паролів, токенів чи сесій не виявлено. Архів ЛР1–3 містить 90 числових вибірок; ЛР6 — чотири знеособлені навчальні набори даних.

- data_analysis_lab1.pdf … data_analysis_lab6.pdf — повні постановки та вимоги до звіту.
- data_lab1-3.zip — три файли vN_1.txt, vN_2.txt, vN_3.txt на кожен варіант 1–30.
- tasks_lab4-5.docx — по дві задачі на варіант. Автоматичну нумерацію Word перевіряти у самому документі; не вгадувати номер за позицією XML.
- data_lab6.zip — ADHD.txt, readingspeed.txt, water.txt, wines.txt; задачу обирати за підтвердженим номером у журналі % 5.

Варіант користувача для АВД ще не підтверджений. Номер 21 з іншого предмета сюди не переносити.
