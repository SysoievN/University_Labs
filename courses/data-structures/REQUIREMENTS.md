# ДС: перевірені вимоги

Реалізувати динамічний дек і методи інтерфейсу; довільна мова/середовище, C++ та Visual Studio рекомендовані. Операції: додавання/видалення з обох кінців, перегляд крайніх елементів, обмін першого й останнього, isEmpty, size, reverse, contains, clear. Передбачити введення й оновлення даних із клавіатури. Для очної форми звіт: постановка задачі, структури вхідних/вихідних даних, текст програми, тести, результати й аналіз. Для дистанційної форми методичка просить прикріпити файл програми в Teams. На захисті — пояснення структури/алгоритму та контрольні запитання. Шрифт і поля в №1 не задані. Ці вимоги не перенесено автоматично на №2–6.

Джерело: вебперегляд Teams, 2026-10-09. Ці вимоги стосуються лише прямо зазначених номерів робіт. Не переносити їх автоматично на інші лабораторні.
