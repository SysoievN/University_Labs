# ДС: перевірені вимоги

Реалізувати динамічний дек і методи інтерфейсу; довільна мова/середовище, C++ та Visual Studio рекомендовані. Операції: додавання/видалення з обох кінців, перегляд крайніх елементів, обмін першого й останнього, isEmpty, size, reverse, contains, clear. Передбачити введення й оновлення даних із клавіатури. Для очної форми звіт: постановка задачі, структури вхідних/вихідних даних, текст програми, тести, результати й аналіз. Для дистанційної форми методичка просить прикріпити файл програми в Teams. На захисті — пояснення структури/алгоритму та контрольні запитання. Шрифт і поля в №1 не задані. Окремо прочитані №2–6 наведено нижче.

Джерело: вебперегляд Teams, 2026-10-09. Ці вимоги стосуються лише прямо зазначених номерів робіт. Не переносити їх автоматично на інші лабораторні.

## Методички №2–6 та спільні правила

№2: skip list, вузол (key,value,Level_Node), шаблонний тип value; вставлення, пошук, вилучення, копіювання, очищення. Перевірити вибір MaxLevel як константи, необмеженого значення або функції (p,N). №3: розріджена матриця на динамічних мультисписках, лише ненульові елементи; вузол value і два вказівники, масиви голів рядків/стовпців; множення на число, транспонування, додавання. №4: k-d дерево 2D/3D, вставлення, вилучення, найближчий сусід. №5: біноміальні дерева, вставлення/вилучення, підрахунок вузлів і дерев; пояснити кількість десятковим та двійковим записом. №6: неорієнтований граф, матриця та списки суміжності, BFS/DFS й остовне дерево.

Усі №1–6: динамічні структури та власні реалізації, введення/зміна даних з клавіатури, зручне довільне виконання операцій. C++/Visual Studio рекомендовані, мову можна обрати. Звіт: мета, умова, вхідні/вихідні дані, класи/методи і діаграма за наявності, лістинг, опис тестів, результати/аналіз, помилки за наявності. Очищений Word-шаблон у sources/redacted/. Числові параметри шрифту/полів методички не задають.

Оцінка кожної лабораторної 10: звіт 0–1, теорія 0–2, програма 0–4, обґрунтування інструментів 1, зміна програми на захисті 2. Підсумковий тест: 40 балів, 100 питань × 0,4, на заліковому тижні; календарної дати не знайдено. Дати №4–6 в тематиці на добу пізніші за Teams; для планування використовувати ранніший строк, часовий пояс уточнити.
